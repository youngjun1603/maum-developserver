# Landing UI Kit — The Light of Life

A high-fidelity recreation of the marketing landing page hero per the brief. Single page; demonstrates header, partner ribbon, hero (headline + subhead + CTAs + trust strip), and scripture card.

## Files
- `index.html` — entry; mounts the React app
- `landing.css` — landing-only styles (uses tokens from `colors_and_type.css`)
- `landing.jsx` — Header, PartnerRibbon, Hero, ScriptureCard, MiniCard

## What's covered
- Sticky navy header with wordmark + nav + login + primary CTA
- Top "official partner" ribbon
- Hero with serif Korean headline ("말씀으로 치유하는 마음"), gold accent on "마음"
- Subhead, gold primary CTA + outline CTA
- Trust row with the three indicators from the brief
- Scripture card (오늘의 말씀) with corner-bracket ornament, ✦ glyph, KR + EN scripture, reference label
- Two action mini-cards beneath scripture (PHQ-9 starter, church inquiry)

## What's intentionally not built
The brief asked specifically for the hero. Below-the-fold sections (counselor directory, assessments grid, testimonials, footer) are out of scope and would be added in a follow-up.
