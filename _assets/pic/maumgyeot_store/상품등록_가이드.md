# 마음곁 스마트스토어 상품 등록 가이드

> 코드는 [/admin](https://maumgyeot.com/admin)에서 발행. (상품 종류 = 코드 종류 매칭 주의)

## 2. 스마트스토어 입력 필드 (공통)

- **카테고리**: 생활/건강 > 반려동물 (적합 항목). ※ 코드성 상품이라 "e쿠폰/상품권" 성격 → 스토어 정책상 적절 카테고리 선택.
- **상품명**: 위 노출용 상품명 사용(검색 키워드 "반려동물 행동 통역, 강아지 고양이 마음" 포함).
- **판매가**: 위 표.
- **상품유형/배송**: **디지털 콘텐츠(배송 없음)**. 배송비 0원. 코드는 **주문 확인 후 구매자에게 직접 전달**(스토어 발송 메시지/문자/메일).
- **재고**: /admin에서 발행한 코드 개수만큼(예: 50개 발행 → 재고 50).
- **대표이미지/추가이미지**: 위 PNG 업로드.
- **상세설명**: 아래 3장 텍스트를 '직접 작성'에 붙여넣거나, 'HTML 작성'에 4장 HTML 사용 + 안내이미지 삽입.

### ⚠️ 운영 주의
- **통신판매업 신고** 필요(스토어 판매 전제). 사업자/신고 상태 먼저 확인.
- **디지털 콘텐츠 환불**: 코드 발송·등록 후 청약철회 제한될 수 있음을 상세설명·고지에 명시(아래 포함).
- 상세설명에 **외부 폼(네이버폼 등)으로 개인정보 수집 금지**(스토어 정책). maumgyeot.com 안내만.

---

## 3. 코드 전달·발행 운영 흐름
1. [/admin](https://maumgyeot.com/admin) 접속 → ADMIN_SECRET 입력.
2. 판매할 상품 종류 선택(sub_light/sub_pro/pack10) → 개수 발행 → **CSV 다운로드**.
3. 스마트스토어 주문 발생 → 구매자에게 **미사용 코드 1개** 전달(발송 메시지).
4. CSV에서 전달한 코드를 사용처리/메모(중복 전달 방지). 발행내역·사용여부는 /admin에서 확인.

## 4. 상세설명 — 직접 작성용 텍스트

### (공통 머리말)
```
🐾 마음곁 — 반려동물의 행동을 읽어 마음을 통역해요

우리 아이가 보내는 행동 신호(꼬리·귀·자세·소리)와 상황을 입력하면,
동물행동학 관점에서 "이런 마음일 수 있어요"를 따뜻하게 풀어드려요.
짧은 영상으로도 통역받을 수 있고, 영상은 분석에만 잠깐 쓰이고 저장하지 않아요.

※ 마음곁은 수의학적 진단·치료가 아니라, 보호자가 아이를 더 이해하도록 돕는 참고용이에요.
   건강이 걱정되는 신호는 "수의사 상담"을 안내해 드려요.
```

· 가끔 필요할 때만 쓰고 싶은 분께 좋아요.
· 가격: 4,900원
