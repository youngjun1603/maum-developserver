# 마음수달 스마트스토어 상품 등록 가이드

> 디지털 콘텐츠(이용권 코드). 구매 → 코드 발송 → 부모님이 maumotter.com '이용권'에 등록 → 즉시 적용.
> **통역 1회 = 또또와의 대화(세션) 1번.** 코드는 [/admin](https://maumotter.com/admin)에서 발행.

## 1. 상품 리스트 (3종 — 각각 별도 상품 권장)
| 상품명(노출용) | 판매가 | 발행 코드 종류(/admin) | 제공 | 대표이미지 |
|---|---|---|---|---|
| 마음수달 아이 마음 통역 구독권 · 라이트(30일) | 4,900원 | `sub_light` | 30일간 매월 30회 통역 | 01_구독_라이트.png |
| 마음수달 아이 마음 통역 구독권 · 프로(30일) | 9,900원 | `sub_pro` | 30일간 매월 100회 통역 | 02_구독_프로.png |
| 마음수달 아이 마음 통역 회차권 · 10회(60일) | 4,900원 | `pack10` | 통역 10회(60일 유효) | 03_회차권_10회.png |

- **추가이미지(공통)**: `00_코드등록_안내.png` 를 세 상품에 추가.
- 이미지 모두 1000×1000(또또 캐릭터 합성).

## 2. 스마트스토어 입력 (공통)
- **카테고리**: 출산/육아 또는 생활 관련(코드성 디지털 상품).
- **상품명**: 위 노출용(키워드 "아이 감정, 속마음, 육아 코칭" 포함).
- **상품유형/배송**: 디지털(배송 없음, 배송비 0). 코드는 주문 확인 후 구매자에게 직접 전달.
- **재고**: /admin 발행 코드 수만큼.
- **상세설명**: 아래 텍스트(직접 작성) 또는 HTML.

### ⚠️ 운영 주의
- **통신판매업 신고** 필요. **디지털 콘텐츠 환불 제한** 고지(아래 포함). 외부 폼 개인정보 수집 금지.

## 3. 코드 발행·전달
1. [/admin](https://maumotter.com/admin) → ADMIN_SECRET 입력 → 종류 선택 → 발행 → CSV 다운로드.
2. 주문 발생 시 미사용 코드 1개 전달, CSV에 사용 메모(중복 방지).

## 4. 상세설명 — 직접 작성 텍스트
```
🦦 마음수달 — 아이의 속마음을 또또가 듣고, 부모님께 통역해요

아이가 화면 속 수달 친구 '또또'와 도란도란 이야기하면,
그 대화를 부모님이 이해·행동할 수 있는 따뜻한 코칭으로 통역해 드려요.
부모님 휴대폰에서, 아이와 함께 사용하는 서비스예요.

※ 마음수달은 의학적 진단·치료가 아니라, 부모님이 아이 마음을 더 이해하도록 돕는 참고용이에요.

[구성]
· 라이트(30일) — 매월 30회 통역 · 4,900원
· 프로(30일) — 매월 100회 통역 · 9,900원
· 회차권(10회) — 60일 유효 1회성 · 4,900원
(이 페이지는 위 중 하나입니다. 상품명을 확인해 주세요.)

[이용권 코드 등록 방법]
1) maumotter.com 접속 후 로그인(부모님 계정, 이메일 가입)
2) 부모 화면의 '🎟️ 이용권' 칸에 구매하신 코드 입력
3) '등록'을 누르면 즉시 적용 (통역 1번 = 또또와의 대화 1번)

[꼭 확인해 주세요]
· 코드는 1인 1회 등록(타인 양도·중복 등록 불가)
· 디지털 콘텐츠 특성상 코드 발송·등록 후 청약철회가 제한될 수 있어요.
· 문의: limyj007@gmail.com
```
