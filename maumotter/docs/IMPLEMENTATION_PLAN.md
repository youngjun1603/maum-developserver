## 구현 단계 (우선순위)

### P0 — 안전(타협 불가) ⭐ 먼저
- **(2) 게이팅:** 부모가 세션 시작 시 PIN 1회 설정/확인. 세션 종료 시 곧바로 리포트를 띄우지 않고 **"부모님께 휴대폰을 전해주세요 → 부모 PIN 입력"** 핸드오프 게이트 후 리포트 노출. 아이는 분석을 못 본다.
- **(3) 세션 시간제한:** 10~15분(기본 12분) 타이머. 경과 시 또또가 자연스럽게 마무리 멘트 후 세션 종료(컴패니언화 차단). 재방문 유도 문구·푸시 없음.
- **(4) AI 정체성 고지:** 또또 첫 인사에 "나는 진짜 동물은 아니고, 네 마음을 들어주는 수달 친구야"를 연령 맞춰 포함 + 첫 진입 시 안내.

### P1 — 연령 사용성(핵심)
- **(10) 음성:** Web Speech `webkitSpeechRecognition`(ko-KR) 마이크 입력 + `speechSynthesis` 또또 TTS 자동 낭독. 연령별 기본 모달리티. 미지원 시 텍스트 폴백. **음성 원본 서버 미전송**.
- **(6) 위기 사전 키워드:** 백엔드에 학대·자해·폭력 키워드 1차 스크리닝 → LLM 판정과 OR(보수적)로 crisis_flag.

### P2 — 부모 화면·정책 완성
- (12) 설정 화면(PIN 변경·면책·개인정보처리방침·마음 시리즈 안내 1곳)
- (13) 아이 등록 폼 성별·관심사 / (14) 대시보드 최근 리포트 요약
- (9) 발화 보관정책 안내·면책 문구 노출

### P3 — 표정 카메라(7-C)
- 온디바이스 표정 분석 + 원본 즉시 폐기, 요약 신호만 메타 입력. (별도 R&D 단계)

## 작업 방식
각 단계 구현 → `tsc` 타입체크 → 배포 → 실동선 테스트 → 커밋. P0 먼저, 안전 검증 후 P1.
