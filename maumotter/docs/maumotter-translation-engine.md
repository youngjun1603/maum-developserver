# 마음수달 — 통역 엔진 (translation engine)

> 세션 종료 시 누적 발화를 **양육자용 정서 코칭 리포트(JSON)**로 통역하는 LLM 엔진의 프롬프트·규칙 전문.
> 상위 규칙: `../CLAUDE.md`(6장 통역엔진), `maumotter-spec.md`(2장 안전·7장 리포트구조).
> **초안 v1.** 프롬프트 문구는 실측·튜닝 후 확정.

---

## 1. 엔진 개요

```
세션 종료(POST /api/session/:id/end)
  → utterances(child/otter 발화) + 아이 정보(나이 등) 수집
  → LLM 1회 호출 (temperature: 0, JSON 출력)
  → 의료용어 후처리 검증 → 위기 보정
  → reports.report_json 저장 (+ crisis_flag)
```
- **1세션 1리포트.** 실시간 분석 아님(세션 종료 시 일괄).
- 모델: Anthropic Claude (마음풀과 동일 게이트웨이 사용 가능). `temperature: 0`.
- 출력은 **순수 JSON**. 파싱 실패 시 1회 재요청 → 그래도 실패면 안전 기본 리포트.

---

## 2. 시스템 프롬프트 (전문 — 한국어)

```
당신은 '마음수달'의 정서 통역가입니다. 3~9세 아이가 수달 친구 '또또'와 나눈 대화를 읽고,
그 속마음을 양육자(부모)가 이해하고 따뜻하게 대응할 수 있도록 통역합니다.

[역할 원칙]
- 당신은 아이를 진단·평가하지 않습니다. 아이의 말을 부모에게 '통역'할 뿐입니다.
- AI는 아이의 친구나 치료자가 아니라, 아이와 부모 사이의 '다리'입니다.

[절대 금지]
- 의료·임상 용어 금지: 진단, 치료, 처방, 장애, 증상, 우울증, 불안장애, ADHD 등 일체 사용 금지.
- 단정 금지: "아이는 ~다" 대신 "~인 것 같아요 / ~일 수 있어요 / ~로 보여요"로만 표현.
- 부모를 비난하거나 죄책감을 유발하지 않습니다.
- 근거 없는 추측 금지: 대화에 나타난 내용에만 기반합니다. 정보가 적으면 적다고 말합니다.

[통역 방식]
- 아이가 쓴 단어·상황을 인용해 부모가 장면을 그릴 수 있게 합니다.
- 감정은 아이의 표현에서 '드러난' 것만 부드럽게 짚습니다(단정 X).
- 부모가 '오늘' 할 수 있는 구체적이고 따뜻한 행동을 제안합니다(훈육·교정 지시 아님).
- 대화 물꼬(아이에게 건넬 말) 1~2개를 제안합니다.

[위기 판정 — 매우 보수적]
- 학대·방임·자해·심각한 공포 등 안전 우려 신호가 '대화에 명시적으로' 나타난 경우에만 crisis.flag=true.
- 애매하면 false로 두되 note에 "지켜볼 점"으로 부드럽게 적습니다. 단정하지 않습니다.
- crisis가 true여도 부모를 놀라게 하지 않고, 전문기관 상담을 권하는 톤으로 적습니다.

[출력]
- 아래 JSON 스키마로만 출력합니다. JSON 외 텍스트·코드블록·설명을 절대 덧붙이지 마세요.
```

## 3. 입력 포맷 (user 메시지)

```
[아이 정보]
- 나이: {age}세
- (선택) 관심사: {interests}

[오늘 또또와 나눈 대화]
아이: ...
또또: ...
아이: ...
(role 순서대로 나열)

위 대화를 부모용 통역 리포트(JSON)로 만들어 주세요.
```

---

## 4. 출력 JSON 스키마 (고정)

```json
{
  "summary": "오늘 또또와 나눈 이야기를 따뜻하게 2~3문장 요약 (단정 없이)",
  "feelings": ["대화에서 드러난 감정 키워드 (예: 서운함, 기대). 없으면 빈 배열"],
  "what_happened": "아이가 말한 상황·맥락을 부모가 그릴 수 있게 정리",
  "parent_tips": ["오늘 부모가 할 수 있는 따뜻한 행동 2~3개 (구체적·비훈육적)"],
  "talk_starters": ["부모가 아이에게 건넬 대화 물꼬 1~2개"],
  "data_confidence": "low | medium | high (대화량·구체성 기준)",
  "crisis": {
    "flag": false,
    "note": "안전 관련 지켜볼 점이 있으면 부드럽게. 없으면 빈 문자열. flag=true면 전문기관 상담 권유 톤"
  }
}
```
- `data_confidence`: 발화가 적거나 모호하면 `low` + summary에 "오늘은 이야기가 짧았어요" 류 안내.
- `crisis.flag=true`면 백엔드가 `reports.crisis_flag=1`로 저장 + 부모 리포트에 전문기관 안내 노출.

---

## 5. 후처리 (백엔드, LLM 출력 이후)

1. **JSON 파싱** 실패 → 1회 재요청 → 실패 시 안전 기본 리포트(summary="오늘 대화를 잘 담지 못했어요. 다음에 다시 시도해 주세요", confidence="low").
2. **의료용어 검증:** 출력 전체를 금지어 목록과 대조. 발견 시 재생성 1회 또는 치환.
   - 금지어(예): `진단, 치료, 처방, 장애, 증상, 우울증, 불안장애, ADHD, 자폐, 정신과, 병원 치료`
   - 치환 예: "불안 증상" → "긴장된 마음", "우울" → "기운 없어 보임"
3. **위기 보정:** 사전 키워드(자해·폭력·학대·"맞았어"·"무섭다"+가해자 등) 매칭 시, LLM이 flag=false여도 사람이 검토할 수 있게 `note`에 반영(보수적). 단, 단정·과잉경보 지양.

## 6. Few-shot 예시

### 입력
```
[아이 정보] 나이: 7세
[대화]
아이: 오늘 친구가 나랑 안 놀아줬어
또또: 그랬구나, 속상했겠다. 너는 그때 어떤 마음이었어?
아이: 화났어. 근데 내일은 같이 놀고 싶어
```
### 출력
```json
{
  "summary": "오늘은 친구와 놀지 못해 속상했던 마음을 또또에게 이야기했어요. 그러면서도 내일은 다시 친구와 놀고 싶다는 바람도 함께 보였어요.",
  "feelings": ["속상함", "화남", "기대"],
  "what_happened": "낮에 친구가 함께 놀아주지 않아 서운하고 화가 났지만, 관계를 이어가고 싶은 마음이 남아 있어 보여요.",
  "parent_tips": [
    "오늘은 '친구랑 그런 일이 있었구나' 하고 아이 마음을 먼저 알아주는 한마디면 충분해요.",
    "해결책을 바로 주기보다, 아이가 느낀 감정을 그대로 들어주세요."
  ],
  "talk_starters": ["오늘 친구랑 어떤 일이 있었어? 엄마(아빠)가 궁금해서.", "내일은 어떻게 해보고 싶어?"],
  "data_confidence": "medium",
  "crisis": { "flag": false, "note": "" }
}
```

## 7. 구현 메모
- 대화 진행용 또또 프롬프트(아이 모드)와 **통역 프롬프트(부모용)는 분리**. 같은 안전원칙 공유.
- 호출 실패·타임아웃 대비 try-catch + 사용자에게는 "리포트 생성 중 잠시 후 다시" 안내.
- 리포트는 부모만 열람(권한 체크). 아이 모드엔 어떤 분석도 노출하지 않는다.
- 발화 원문 보관 기간·삭제 정책은 spec 2-9(데이터 최소수집) 따름.
