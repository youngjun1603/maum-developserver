# 마음곁 — 행동 사전 (behavior library)

> 개·고양이 행동 신호의 **후보 의미·다의성·맥락 주의**를 정리한 시드 데이터/도감 소스.
> 통역 엔진 프롬프트 주입용 + 보호자 도감 콘텐츠. **종 완전 분리.** ⚠️ = 다의적(정반대 의미 가능) 신호.
> 상위: `../CLAUDE.md`(3장 황금률), `maumgyeot-translation-engine.md`. **초안 v1 — 행동학 문헌 기반, 확장 예정.**

> ⚠️ 모든 의미는 **"~일 수 있음"**(단정 아님). 단일 신호로 판단 금지 — 꼬리·귀·눈·자세·발성을 **함께** 읽고 맥락으로 보정. 건강 관련은 진단이 아니라 **수의사 상담 권장**.

## A. 고양이 (cat) — 우선 구현

### A-1. 발성
| 신호 | 후보 의미 | 다의성·주의 |
|------|-----------|-------------|
| 골골거림(purr) | 만족·편안, 애착 | ⚠️ **통증·불안 시 자가진정**으로도 나옴. 다른 불편 신호 동반 시 주의 |
| 짧은 야옹(짧고 높게) | 인사·관심 요청 | 사람 향한 소통(고양이끼리는 잘 안 씀) |
| 길게/반복 우는 소리 | 요구(밥·문 열기)·불만 | 노령묘 야간 발성은 건강 신호일 수 있음 → health |
| 하악질/그르렁(낮게) | 위협·두려움·경계 | 접근 멈추라는 명확한 거리 요청. 강제 접촉 금지 |
| 채터링(이빨 떨듯) | 사냥 흥분(창밖 새 등) | 좌절·기대 |

### A-2. 꼬리
| 신호 | 후보 의미 | 주의 |
|------|-----------|------|
| 꼬리 수직(끝 살짝 까딱) | 반가움·우호 | 대표적 긍정 신호 |
| 꼬리 부풀림(브러시) | 놀람·공포·방어 | 몸도 옆으로 부풀면 강한 경계 |
| 꼬리 빠르게 좌우 탁탁 | 짜증·각성↑ | ⚠️ 개의 '흔들기=반가움'과 **정반대**. 멈춤 신호 |
| 꼬리 다리 사이/낮게 | 불안·복종 | |

### A-3. 귀 · 눈
| 신호 | 후보 의미 | 주의 |
|------|-----------|------|
| 귀 정면·이완 | 편안·관심 | |
| 귀 옆으로/뒤로 납작(비행기 귀) | 두려움·공격 직전 | 접근 중단 |
| 느린 눈깜빡임 | 신뢰·애정("고양이 키스") | 마주 천천히 깜빡여 화답 가능 |
| 동공 확대(밝은데도) | 흥분·공포·각성 | 맥락 필요(놀이 흥분 vs 공포) |

### A-4. 몸짓 · 행동
| 신호 | 후보 의미 | 주의 |
|------|-----------|------|
| 부비기(bunting, 머리·몸) | 친밀·영역표시(안심) | 신뢰 표현 |
| 꾹꾹이(앞발 누르기) | 안정·애착(유년기 잔재) | |
| 배 보이기 | 편안·신뢰 | ⚠️ 만져달라는 뜻 **아닐 수 있음**(방어자세일 수도) |
| 그루밍 과다/특정부위 집착 | 스트레스·가려움·통증 | health 가능 → 수의사 |
| 숨기·식욕저하·화장실 밖 배변 | 스트레스 또는 몸 불편 | **health_flag** 우선 → 수의사 상담 |

## C. 공통 규칙 (엔진 적용)
- 신호 코드별로 `species`·`meanings[]`·`ambiguous(bool)`·`health_relevant(bool)` 필드로 시드화 → API `/api/behavior?species=` 로 제공(신호 선택 UI + 프롬프트 주입).
- ⚠️ ambiguous 신호는 리포트 `caveat`에 반드시 반영.
- health_relevant 신호 또는 식욕·배변·기력·통증 키워드 → `health_flag=true` + 수의사 권장(진단 아님).
- **개 신호를 고양이 통역에, 또는 그 반대로 섞지 않는다.**

## D. 출처·확장 메모
- 1차 시드는 일반 동물행동학·반려동물 행동 자료 기반의 보편 신호. 품종·개체차 큼 → "참고용·단정 아님" 일관 유지.
- 확장 시: 신호 추가는 이 문서 → 코드 시드 → API 순. 의미는 보수적으로(과대해석 금지).
