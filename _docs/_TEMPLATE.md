# 설계서 표준 템플릿 (maum 전 서비스 공통)

> 각 서비스 폴더의 `docs/DESIGN.md` 는 아래 목차를 **순서·제목 그대로** 따른다.
> 해당 없는 섹션은 삭제하지 말고 `해당 없음` 으로 남긴다. 목차가 같아야 서비스 간 비교가 된다.
>
> **작성 원칙**
> - 근거는 코드·설정·CLAUDE.md·migrations 다. 추측으로 쓰지 않는다.
> - 코드에서 확인되지 않은 항목은 `⚠️ 미확인` 으로 표기하고 비워둔다.
> - 기능 "현황"은 배포 여부까지 구분한다: `배포됨` / `구현·미배포` / `설계만` / `보류`.
> - CLAUDE.md 가 외부 메모리(`project_xxx`)를 참조하는 항목은 그 사실을 명시한다.
